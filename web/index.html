04 / ABOUT THIS RELEASE

Method and limits

Five candidates were scored on chronological 14-day windows. Selection used validation MAE and a 1% improvement gate over seasonal naive, then the held-out test was evaluated once. The serving model uses only targets through 2012-10-22.
