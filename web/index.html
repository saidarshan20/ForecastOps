03 / INDEPENDENT 1-DAY REPLAY

Historical error monitor

70 daily refits and day-ahead forecasts, 2012-10-23 to 2012-12-31. This replay is separate from the five 14-day test windows and the fixed model used above.

How are replay flags calculated?

Error versus seasonal naive is flagged when the selected model’s latest 28-day MAE exceeds the baseline’s by more than 20%. Change from initial error is flagged when a later, nonoverlapping 28-day window exceeds the first window’s MAE by more than 20%. A zero reference does not trigger a relative flag. If seasonal naive itself is selected, only change from initial error is used. These checks do not change model selection or retrain the serving model.

04 / ABOUT THIS RELEASE

Method and limits

Five candidates were scored on chronological 14-day windows. Selection used validation MAE and a 1% improvement gate over seasonal naive, then the held-out test was evaluated once. The serving model uses only targets through 2012-10-22.
